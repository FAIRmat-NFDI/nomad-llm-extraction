This package is for a generalised llm data extraction pipeline. It is designed to be used in the context of the nomad-lab, but can be used in other contexts as well. The package provides a set of tools for extracting data from LLMs, and for processing that data in a way that is useful for scientific research. 
I want to use this package to extract data from LLMs in a way that is useful for scientific research. I want to be able to use the tools provided by this package to extract data from LLMs, and to process that data in a way that is useful for scientific research. I also want to be able to use this package in the context of the nomad-lab, but I want it to be general enough to be used in other contexts as well.
To see what is missing from the package I want to recreate the pipeline from https://github.com/lamalab-org/perla-extract/ with the main parts in https://github.com/lamalab-org/perla-extract/blob/main/src/perla_extract/pipeline.py. I did a small replication of it in domains/perovskite_solar_cell/ in this package.  The initial extraction pipeline I want to it to be configurable based on the system/instruction prompt, the nomad mdef+schema optimizer or a direct user provided json schema, the model to use with litellm. The pipeline would directly take text as its input. 
The pipeline should be such that it can be easily extended to include more steps in the future, such as a step for validating the extracted data against a reference dataset, or a step for visualizing the extracted data. The pipeline should also be such that it can be easily integrated into other workflows, such as a workflow for training a machine learning model on the extracted data. 
A future aim would be have to an agent optimise botht the prompt and the schema based on the feedback from the validation step so it needs to be designed in a way that allows for easy integration of such an agent in the future. The package should also be well-documented.
